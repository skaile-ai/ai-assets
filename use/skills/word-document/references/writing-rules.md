# Writing rules

Default rules for prose in an organization's Word documents. **The
organization's own style guide or template overrides every rule here.** Apply a
rule from this file only where the organization has not set its own.

## Structure

- Headings go no deeper than three levels: the document's level-1 to level-3
  heading styles, by their real names from `style.list`.
- Headings have no full stop.

## Punctuation and typography

- No double spaces.
- No manual line breaks to align text; they break when the document is
  reformatted. Use paragraphs, Named styles or tables instead.

## Numbers, units and currency

- In running text, write out the numbers one to twelve; use numerals from 13
  upward. Numbers in tables are always numerals.
- Put a non-breaking space between a number and its unit (`5 kg`).
- Write amounts with the ISO 4217 three-letter currency code, a non-breaking
  space, then the amount (`EUR 100`).

## Dates

- In tables, use ISO 8601 (`2026-08-25`).

## Abbreviations

- On first mention, write the full term followed by the abbreviation in
  brackets, then use only the abbreviation: Service Level Agreement (SLA).

## Lists

- Use a full stop after every bullet point or after none.
- Keep bullets grammatically consistent: all start with a verb, or all are
  nouns.
