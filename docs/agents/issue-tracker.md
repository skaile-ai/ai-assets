# Issue tracker: github

Repo: skaile-ai/ai-assets

Issues live in GitHub issues of skaile-ai/ai-assets: `gh issue list`, `gh issue view <n>`, `gh issue create`.
Specs/plans are parent issues labelled `plan`; tickets are sub-issues (`gh issue create --parent <n> --label ready-for-agent`) with native blocked-by links (`--blocked-by <n>`).
No local ticket files under `.scratch/`.
